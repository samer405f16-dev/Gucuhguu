کد آماده برای پیست تو Termux


    

      این متن رو کامل کپی کن و تو Termux پیست کن. خودش پیش‌نیازها (پایتون و تله‌تان) رو نصب می‌کنه،
      فایل بات رو می‌سازه و اجراش می‌کنه. بعدش فقط شماره، کد تلگرام و رمز دو مرحله‌ای (اگه داشت) رو می‌پرسه.
    

  


  

    
آموزش استفاده

    
    
      
  1. اپ Termux رو از F-Droid نصب کن (نسخه‌ی گوگل‌پلی قدیمیه و کار نمی‌کنه).
    2. 
      
  2. بالا اطلاعات اکانت و قابلیت‌های دلخواه رو تنظیم کن و «ساخت کد Termux» رو بزن.
    3. 
      
  3. دکمه‌ی «کپی همه» رو بزن، برو تو Termux و همون‌جا پیست کن (نگه‌داشتن روی صفحه → Paste) و Enter بزن.
    4. 
      
  4. خودش اول پیش‌نیازها رو نصب می‌کنه، بعد فایل بات رو می‌سازه و اجراش می‌کنه.
    5. 
      
  5. ازت شماره (با کد کشور، مثل +98912xxxxxxx)، کد تلگرام و در صورت داشتن رمز دو مرحله‌ای رو می‌پرسه؛ همونجا وارد کن.
    6. 
      
  6. وقتی Running... اومد، تو Saved Messages بنویس راهنما تا لیست همه‌ی دستورات رو ببینی.
    7. 
      
  7. برای اینکه بعد از بستن Termux هم روشن بمونه:
        
    pkg install tmux -y
        
    tmux new -s bot
        
    python bot.py
        
    بعد Ctrl+B و سپس D بزن تا پشت‌صحنه بمونه.
      
    8.
